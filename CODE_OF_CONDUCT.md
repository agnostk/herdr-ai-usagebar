# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
discussion about the work. Harassment, personal attacks, and publishing other
people's private information are not tolerated in issues, pull requests, or
any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@agnostk](https://github.com/agnostk), through a
[private report](https://github.com/agnostk/herdr-ai-usagebar/security/advisories/new)
marked *conduct*. Reports are kept confidential. The maintainer may remove
comments, lock threads, or block contributors who break these rules, as
described in the Covenant's enforcement guidelines.
